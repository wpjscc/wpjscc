#### 🔭 What I build

- **[reactphp-x](https://github.com/reactphp-x) — an async PHP ecosystem on ReactPHP:** framework core & workers, microservices (RPC, register-center, gateway, websocket-center), connection pools (MySQL / Redis), async database & Cycle ORM, S3 filesystem, queue, session, JWT, middleware (route / SSE / websocket), and utilities (crontab, tail, log, process-manager).
- **Async PHP building blocks:** HTTP/TCP/SSH proxies, WebSocket servers, master-worker processes, rate limiters/concurrency control, and streaming tails.
- **Laravel / WinterCMS:** `laravel-reactphp` integration, Laravel Zero apps, and reusable WinterCMS plugins (API, UI, OSS, Twig, WeChat, JSON, and more) with Chinese documentation.
- **Networking & proxy tooling:** intranet penetration (内网穿透), TCP/HTTP/SSH proxying, and a KCP PHP extension.
